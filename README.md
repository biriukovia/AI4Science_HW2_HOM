## Воспроизведение

Python 3.12.10, NumPy 2.5.4, SciPy 1.18.1. В окружении Python:

```bash
git clone https://github.com/biriukovia/AI4Science_HW2_HOM.git
cd AI4Science_HW2_HOM
git checkout hw2
python -m pip install -r requirements-hw2.txt
python checks/hw2/verify.py --stage full
```

Ожидается код **0**, восемь свойств PASS. В ветке `codex/hw2-double-pass`
(коммит `d95b8f0`) ожидается код **1** и FAIL P8.
Goose, Ollama и ключи API для воспроизведения не нужны.

## История и границы результата

Перенесена история только файлов этого пакета; даты и авторы сохранены.
[Соответствие коммитов](results/hw2/history_map.json) объясняет исходные
идентификаторы и пути в неизменённых журналах. Комментарии в проверяющем
коде о полном архиве Goose относятся к исходному рабочему проекту.
Метка `hw2` фиксирует пакет для проверки. Пройденные тесты подтверждают
численные свойства реализации в заявленной области, а не истинность
физической модели. Официальный check_week6.py пропущен с разрешения пользователя.
