# HW2: проверка реализации HOM-модели

## Проверка

Установить зависимости: `python -m pip install -r requirements-hw2.txt`.
Одна команда верификатора из корня репозитория:

```bash
python checks/hw2/verify.py --stage full
```

Код 0 — все восемь свойств пройдены на 640 наборах; код 1 — отказ или ошибка.
Статистический вывод сравнения записывается отдельно. Результат нового запуска —
results/hw2/current.json; архивные результаты не перезаписываются.

## Границы

Методика — METHOD.md, отчёт — reports/hw2/report.md, метка сдачи — hw2.
Не менять данные, критерии, пороги или проверки ради успешного вердикта.
Отрицательный контроль находится в ветке codex/hw2-double-pass; его код 1 ожидаем.
Не запускать новый фит и не делать выводов об истинности физической модели.
Не выдумывать личную проверку, попытки или приёмку. Сохранять реальные ошибки.
